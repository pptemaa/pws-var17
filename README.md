# Практическое задание 1 — Вариант 17

Прикладная разработка серверных частей веб-приложений на языке Python.  
ИКБО-71-24.

## Описание

Прототип веб-приложения с поддержкой удалённого вызова процедур на основе
протокола TCP. Данные хранятся в памяти. Схема данных: `Participant`,
`Assignment`, `Result`.

## Этап 1 — Модель слоя доступа к данным

Реализованы операции создания, удаления и получения записей для каждой
сущности, а также выборка с JOIN по формуле реляционной алгебры из задания.
Поддерживается интерактивный режим (REPL).

## Требования

- Python 3.12+
- pytest (для запуска тестов)

```bash
pip install pytest
```

## Запуск

```bash
# REPL
make run

# Тесты
make test
```

## Структура

```
src/
  model.py   — модель слоя доступа к данным
  repl.py    — интерактивный режим (REPL)
tests/
  test_model.py — тесты модели
```
